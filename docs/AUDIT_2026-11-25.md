# Mikayala — audit du 25/11/2026 (sécurité, chat, jeux)

Vérifié sur la base Supabase réelle (journaux, droits, règles) et dans le code.
Limite : rien n'a pu être essayé sur les téléphones ; la compilation et les tests unitaires passent en CI.

## Sécurité

| Point | Avant | Maintenant |
|---|---|---|
| Rôle « anon » (clé incluse dans l'APK, dépôt public) | droits complets sur la plupart des tables (bloqués seulement par la RLS) | **aucun droit** sur les tables publiques |
| TRUNCATE (ignore la RLS) | accordé aux utilisateurs connectés | **retiré** |
| Table `couples` | tout modifiable par un membre (membres, statut…) | seule la durée des messages éphémères est modifiable |
| Nouveau message | pouvait arriver déjà « lu » ou au nom d'un autre | expéditeur et coches fixés par le serveur |
| Messages modifiés par le partenaire | (mises à jour refusées) | réactions/jeux/coches oui ; texte et suppression pour tous : expéditeur seul |
| Fonctions sans contrôle d'appartenance (`edit_message_content`, `delete_message_for_*`) | présentes | **supprimées** |
| Déclencheur de notifications web (`smart-api`) contenant la clé service_role | actif, en échec | **supprimé** |
| Sauvegarde Android (messages, session, code) vers Google / autre téléphone | autorisée | **désactivée** |
| Trafic non chiffré (http) | permis sur Android < 9 | **interdit** |
| Code P2P dans les journaux | écrit en clair | retiré |
| Secrets dans le dépôt public | aucune clé service_role ni clé anon trouvée dans l'historique | — |

Reste à faire (côté propriétaire) :
- clé de compte de service Firebase à coller dans Supabase (`FCM_SERVICE_ACCOUNT_JSON`) ;
- restreindre la clé API Firebase du fichier `public/assets/aistudio/google-services__2__e462f8b7.json` (console Google Cloud → Identifiants → restreindre à l'appli Android `com.mikayla.app`), ou rendre le dépôt privé ;
- comptes anonymes : 183 profils créés au fil des tests ; les anciens peuvent être supprimés depuis Supabase → Authentication.
